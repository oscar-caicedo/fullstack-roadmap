# 🛠️ Etapa 0 — Preparación del Entorno y Control de Versiones

### 🎯 Objetivo
Preparar el entorno de desarrollo profesional, dominar la terminal y aprender el flujo de trabajo esencial con Git y GitHub.

---

## 📚 Conceptos a Dominar

### 1. Terminal y Sistema de Archivos
- [ ] Navegación por rutas relativas y absolutas (`cd`, `dir` / `ls`, `pwd`).
- [ ] Creación y gestión de carpetas y archivos (`mkdir`, `touch` / `ni`, `rm`).
- [ ] Ejecución de programas desde la terminal (`python script.py`, `node script.js`).
- [ ] Variables de entorno básicas (`PATH`, `.env`).

### 2. Control de Versiones con Git
- [ ] `git init`: Inicializar un repositorio local.
- [ ] `git status`: Comprobar el estado de los archivos (untracked, modified, staged).
- [ ] `git add <archivo>` o `git add .`: Preparar cambios (staging area).
- [ ] `git commit -m "mensaje claro"`: Guardar una versión histórica de los cambios.
- [ ] `git log --oneline`: Consultar el historial de commits.
- [ ] `git branch`: Manejo de ramas (`git checkout -b feature/nueva-funcionalidad` o `git switch -c`).
- [ ] `git merge`: Integración de ramas.
- [ ] `git remote add origin <url>`: Conectar con un repositorio remoto en GitHub.
- [ ] `git push -u origin main`: Subir cambios a la nube.
- [ ] `git pull`: Descargar y sincronizar cambios remotos.
