# 🧮 Ejercicio 01 — Calculadora Básica

### 🎯 Objetivo
Crear un programa que solicite dos números y una operación matemática (+, -, *, /) y muestre el resultado, manejando posibles errores del usuario.

### 📋 Requisitos
1. Solicitar el primer número, el segundo número y la operación a realizar.
2. Realizar la operación correspondiente según la opción elegida.
3. Manejar la división por cero (`ZeroDivisionError` o validación con condicional) para evitar que el programa se detenga con un error inesperado.
4. Validar que las entradas sean números válidos (`try / except ValueError`).
5. Permitir realizar múltiples cálculos hasta que el usuario decida salir.

### 🚀 Archivo principal
Escribe tu código en [`calculadora.py`](./calculadora.py).
