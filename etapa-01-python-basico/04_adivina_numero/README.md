# 🎲 Ejercicio 04 — Juego de Adivinar el Número

### 🎯 Objetivo
Juego interactivo donde el computador genera un número secreto aleatorio y el usuario intenta adivinarlo con retroalimentación.

### 📋 Requisitos
1. Usar el módulo `random` (`random.randint(1, 100)`).
2. Indicar si el intento del usuario es "Demasiado alto" o "Demasiado bajo".
3. Contar el número de intentos realizados.
4. Definir un límite de intentos (opcional: niveles de dificultad fácil, medio, difícil).
5. Preguntar si el usuario desea jugar otra partida al terminar.
6. Archivo principal: [`adivina_numero.py`](./adivina_numero.py).
