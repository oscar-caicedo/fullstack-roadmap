# 📦 Ejercicio 06 — Sistema de Inventario Básico

### 🎯 Objetivo
Crear un sistema CRUD (Crear, Leer, Actualizar, Eliminar) en consola para gestionar productos usando diccionarios.

### 📋 Requisitos
1. Cada producto debe tener: ID único, nombre, precio y cantidad en stock.
2. Menú de opciones:
   - 1. Registrar nuevo producto.
   - 2. Listar productos existentes con formato de tabla.
   - 3. Actualizar precio o stock de un producto por ID.
   - 4. Eliminar producto por ID.
   - 5. Salir.
3. Validaciones completas (no duplicar IDs, precios y stocks no negativos).
4. Archivo principal: [`inventario.py`](./inventario.py).
