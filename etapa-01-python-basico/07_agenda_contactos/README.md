# 📇 Ejercicio 07 — Agenda de Contactos

### 🎯 Objetivo
Gestionar contactos personales con búsquedas inteligentes y validación de datos.

### 📋 Requisitos
1. Contactos con: Nombre, Teléfono, Correo electrónico y Categoría (Familia, Trabajo, Amigos).
2. Opciones:
   - Agregar contacto.
   - Listar todos los contactos.
   - Buscar contacto por nombre (búsqueda parcial insensible a mayúsculas/minúsculas).
   - Editar teléfono o correo.
   - Eliminar contacto.
3. Archivo principal: [`agenda.py`](./agenda.py).
