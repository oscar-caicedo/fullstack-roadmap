# ✅ Ejercicio 10 — Programa de Gestión de Tareas (CLI To-Do)

### 🎯 Objetivo
Construir una lista de tareas pendientes por consola con cambio de estados y prioridades.

### 📋 Requisitos
1. Cada tarea tiene: ID autoincremental, título, prioridad (Alta, Media, Baja) y estado (`Pendiente` o `Completada`).
2. Funcionalidades:
   - Agregar tarea.
   - Listar todas las tareas (con indicador visual ej. `[X]` completada, `[ ]` pendiente).
   - Marcar tarea como completada por ID.
   - Eliminar tarea por ID.
   - Filtrar tareas por estado o prioridad.
3. Archivo principal: [`gestion_tareas.py`](./gestion_tareas.py).
