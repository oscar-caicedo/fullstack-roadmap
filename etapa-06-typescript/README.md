# 🔷 Etapa 6 — TypeScript: Tipado Estático y Robustez

### 🎯 Objetivo
Añadir tipado estático a JavaScript para prevenir errores en tiempo de desarrollo, mejorar el autocompletado y preparar la base para aplicaciones de gran escala.

---

## 📚 Conceptos Clave
- [ ] Configuración de TypeScript (`tsconfig.json`, `tsc`).
- [ ] Tipos primitivos y tipos inferidos.
- [ ] Interfaces vs. Type Aliases (`interface` vs `type`).
- [ ] Enums y Union Types (`'PENDING' | 'PAID' | 'FAILED'`).
- [ ] Funciones tipadas (parámetros y valores de retorno).
- [ ] Generics (`<T>`) para funciones y estructuras reutilizables.
- [ ] Tipado de respuestas asíncronas (`Promise<Product[]>`).

---

## 🏆 Proyecto de Etapa: Migración de la Tienda a TypeScript
- [ ] Migrar el proyecto de la tienda a archivos `.ts`.
- [ ] Definir interfaces estrictas para `Product`, `CartItem`, `User`, `Order`.
- [ ] Compilar sin ningún error de TypeScript (`strict: true`).
