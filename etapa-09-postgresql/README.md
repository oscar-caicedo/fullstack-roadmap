# 🐘 Etapa 9 — Bases de Datos Relacionales con PostgreSQL

### 🎯 Objetivo
Aprender a diseñar, modelar y consultar bases de datos relacionales con PostgreSQL y conectarlas al backend de Express mediante SQL y ORMs/Query Builders (Prisma o TypeORM/Kysely/pg).

---

## 📚 Conceptos Clave
- [ ] Modelo Relacional: Tablas, Columnas, Filas, Tipos de datos SQL.
- [ ] Claves primarias (`PRIMARY KEY`) y foráneas (`FOREIGN KEY`).
- [ ] Relaciones: 1 a 1, 1 a N, N a M (tablas intermedias).
- [ ] Lenguaje SQL: `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `LIMIT`, `OFFSET`.
- [ ] Modificación de datos: `INSERT INTO`, `UPDATE`, `DELETE`.
- [ ] Consultas avanzadas: `INNER JOIN`, `LEFT JOIN`, agregaciones (`COUNT`, `SUM`, `AVG`).
- [ ] Índices para optimización de consultas.
- [ ] Transacciones ACID (`BEGIN`, `COMMIT`, `ROLLBACK`) para operaciones críticas (como descontar stock al comprar).

---

## 🏆 Proyecto de Etapa: Conexión React → Express → PostgreSQL
- [ ] Diseñar esquema SQL para productos, usuarios, categorías, órdenes e items de orden.
- [ ] Migrar el backend de Node.js para que guarde y lea datos desde PostgreSQL.
- [ ] Comprobar persistencia real conectando el frontend con la base de datos a través del backend.
