# 🐳 Etapa 13 — Docker y Contenedores

### 🎯 Objetivo
Empaquetar la aplicación y sus dependencias en contenedores reproducibles para asegurar que funcione idénticamente en cualquier máquina o servidor.

---

## 📚 Conceptos Clave
- [ ] Conceptos: Imagen vs. Contenedor, Capas, Daemon de Docker.
- [ ] Creación de `Dockerfile` para Frontend (build multi-etapa con Nginx) y Backend (Node.js).
- [ ] `.dockerignore` para excluir archivos innecesarios.
- [ ] Volúmenes para persistencia de datos (PostgreSQL).
- [ ] Redes internas de Docker (*bridge networks*).
- [ ] Orquestación local con `docker-compose.yml` (Frontend + Backend + PostgreSQL en un solo comando `docker compose up -d`).
