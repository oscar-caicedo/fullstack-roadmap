# 🐧 Etapa 14 — Servidores Linux / Ubuntu

### 🎯 Objetivo
Aprender a operar y administrar servidores basados en Linux (Ubuntu Server), manejando la terminal remota vía SSH y la gestión de procesos.

---

## 📚 Conceptos Clave
- [ ] Conexión remota por SSH (`ssh usuario@servidor`).
- [ ] Comandos esenciales de Linux: `sudo`, `systemctl`, `journalctl`, `htop`, `ps`, `kill`, `chown`, `chmod`.
- [ ] Permisos de archivos (rwx, notación octal).
- [ ] Gestión de paquetes con `apt` (actualización, instalación de Node, Docker, etc.).
- [ ] Variables de entorno del sistema (`/etc/environment`, `.bashrc`).
- [ ] Configuración básica de firewall con UFW (`ufw allow ssh`, `ufw allow http`, `ufw allow https`).
