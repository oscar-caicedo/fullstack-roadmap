# 🔄 Etapa 16 — Tecnologías Alternativas y Comparativas

### 🎯 Objetivo
Habiendo consolidado el stack principal (React + Node.js + PostgreSQL), explorar y comparar alternativas para ampliar el criterio arquitectónico.

---

## 📚 Ecosistemas a Explorar
- [ ] **Frontend**: React vs. Angular vs. Vue / Svelte.
- [ ] **Backend**: Express vs. NestJS vs. Python (FastAPI / Django) vs. Java (Spring Boot).
- [ ] **Bases de Datos Relacionales**: PostgreSQL vs. MySQL.
- [ ] **Bases de Datos NoSQL**: MongoDB / Redis (cuándo usarlas y cuándo no).
