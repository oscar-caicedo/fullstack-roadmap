## 📜 Reglas de Oro

1. **No avanzar por calendario, sino por dominio:** Terminar un curso no significa dominar el tema. Construir algo sin tutorial sí.
2. **Entender antes de copiar:** Prohibido memorizar código o copiar fragmentos sin saber qué hace cada línea.
3. **Intentar resolver primero de forma autónoma:** Leer errores en consola, depurar y consultar documentación oficial.
4. **Git desde el primer día:** Cada ejercicio y avance debe quedar registrado con commits descriptivos.
5. **Bitácora de errores:** Documentar los bugs encontrados y cómo se solucionaron para consolidar el aprendizaje.
6. **Proyectos funcionales por etapa:** Cada etapa concluye con un entregable programado y probado por ti.
7. **Cuidar el orden de aprendizaje:**
   * No React sin buen JavaScript.
   * No Express sin entender HTTP y JS asíncrono.
   * No Docker sin entender cómo corre la app localmente.
   * No frameworks múltiples a la vez.

## 🎯 Criterio de Aprobación para Avanzar de Nivel

Antes de pasar a la siguiente etapa, debes responder afirmativamente a:

- [ ] ¿Qué problema resuelve esta tecnología?
- [ ] ¿Qué está ocurriendo internamente a grandes rasgos?
- [ ] ¿Puedo construir un programa pequeño desde cero sin tutorial?
- [ ] ¿Puedo leer código de otra persona en este stack y entenderlo?
- [ ] ¿Puedo detectar y solucionar errores habituales?
- [ ] ¿Puedo explicar con mis palabras lo que hice y por qué?
- [ ] ¿Puedo modificar o ampliar una funcionalidad sin romper todo el sistema?
