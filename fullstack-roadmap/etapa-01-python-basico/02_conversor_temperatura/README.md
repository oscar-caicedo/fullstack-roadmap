# 🌡️ Ejercicio 02 — Conversor de Temperatura

### 🎯 Objetivo
Permitir convertir temperaturas entre Celsius, Fahrenheit y Kelvin.

### 📋 Requisitos
1. Menú interactivo para elegir la conversión (ej. C -> F, F -> C, C -> K, etc.).
2. Validar que la temperatura ingresada sea un número float válido.
3. Fórmulas:
   - $F = (C \times 9/5) + 32$
   - $C = (F - 32) \times 5/9$
   - $K = C + 273.15$
4. Validar temperaturas por debajo del cero absoluto ($0\text{ K} / -273.15\text{ °C}$).
5. Archivo principal: [`conversor_temp.py`](./conversor_temp.py).
