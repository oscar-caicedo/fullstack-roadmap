# 💱 Ejercicio 03 — Conversor de Monedas

### 🎯 Objetivo
Construir un conversor de divisas con tasas de cambio predefinidas y validación de cantidades positivas.

### 📋 Requisitos
1. Definir al menos 3-4 monedas (ej. USD, EUR, COP, MXN, etc.) usando un diccionario para las tasas.
2. Solicitar al usuario el monto a convertir, moneda de origen y moneda de destino.
3. Validar que el monto no sea negativo ni cero.
4. Formatear la salida con 2 decimales y símbolo de moneda.
5. Archivo principal: [`conversor_monedas.py`](./conversor_monedas.py).
