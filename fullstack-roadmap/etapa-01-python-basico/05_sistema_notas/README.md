# 📝 Ejercicio 05 — Sistema de Calificaciones y Notas

### 🎯 Objetivo
Gestionar una lista de calificaciones de estudiantes, calcular métricas y determinar estados de aprobación.

### 📋 Requisitos
1. Permitir ingresar nombres de estudiantes y sus respectivas notas (entre 0.0 y 5.0 o 0 y 100).
2. Validar que la nota esté en el rango permitido.
3. Calcular: Promedio general del grupo, Nota más alta y Nota más baja.
4. Mostrar listado formateado con nombre, nota y estado ("Aprobado" si >= 3.0 / 60, "Reprobado" en caso contrario).
5. Archivo principal: [`sistema_notas.py`](./sistema_notas.py).
