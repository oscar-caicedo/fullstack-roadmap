# 🏧 Ejercicio 08 — Simulación de Cajero Automático (ATM)

### 🎯 Objetivo
Simular la lógica financiera de un cajero automático con autenticación mediante PIN y control de saldo.

### 📋 Requisitos
1. Autenticación con PIN (máximo 3 intentos antes de bloquear la cuenta temporalmente).
2. Opciones:
   - Consultar saldo disponible.
   - Depositar dinero (validar monto positivo).
   - Retirar dinero (validar fondos suficientes y montos válidos).
   - Ver historial de transacciones de la sesión.
   - Salir y expulsar tarjeta.
3. Archivo principal: [`cajero.py`](./cajero.py).
