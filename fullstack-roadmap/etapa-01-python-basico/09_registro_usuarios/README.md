# 👤 Ejercicio 09 — Sistema de Registro y Login de Usuarios

### 🎯 Objetivo
Aprender a manejar credenciales de usuarios, validaciones de seguridad de contraseñas y control de sesiones simples en consola.

### 📋 Requisitos
1. Registro de usuario:
   - Nombre de usuario único (no repetido).
   - Contraseña segura: longitud mínima de 6-8 caracteres, al menos un número y una letra mayúscula.
2. Inicio de sesión:
   - Verificación de usuario existente y coincidencia de contraseña.
3. Menú post-login:
   - Saludo personalizado, ver perfil, cambiar contraseña, cerrar sesión.
4. Archivo principal: [`registro_usuarios.py`](./registro_usuarios.py).
