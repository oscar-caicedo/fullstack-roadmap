# 🐍 Etapa 1 — Programación desde Cero (Python)

### 🎯 Objetivo
Aprender a pensar como programador, dominar las estructuras de datos y control de flujo en Python, y construir soluciones robustas con validación de errores.

---

## 📖 Temas Clave

1. **Fundamentos**: Variables, tipos de datos (`str`, `int`, `float`, `bool`), operadores aritméticos y lógicos, entrada (`input()`) y salida (`print()`, f-strings).
2. **Control de Flujo**: Condicionales (`if`, `elif`, `else`), comparaciones y lógica booleana.
3. **Bucles**: `for` (iteración sobre rangos y secuencias), `while` (bucles condicionales), control con `break` y `continue`.
4. **Estructuras de Datos**: Listas (`list`), Tuplas (`tuple`), Diccionarios (`dict`), Conjuntos (`set`). Métodos y operaciones comunes.
5. **Funciones**: Definición (`def`), parámetros, argumentos posicionales y nombrados, valor de retorno (`return`), alcance de variables (*scope*), funciones puras y reutilizables.
6. **Manejo de Errores y Validaciones**: Bloques `try / except`, captura de excepciones específicas (`ValueError`, `KeyError`, `ZeroDivisionError`), validación de entradas de usuario.
7. **Modularización y Archivos**: Creación de módulos propios, `import`, lectura y escritura básica de archivos (`open()`, `json`).

---

## 🏋️ Ejercicios de Práctica

Cada ejercicio debe desarrollarse en su respectiva carpeta:

- [ ] `01_calculadora/` — Calculadora con operaciones básicas (+, -, *, /) y manejo de división por cero.
- [ ] `02_conversor_temperatura/` — Conversión bidireccional entre Celsius, Fahrenheit y Kelvin.
- [ ] `03_conversor_monedas/` — Conversor con tasas de cambio y validación de montos positivos.
- [ ] `04_adivina_numero/` — Juego con generación aleatoria (`random`), pistas (más alto/más bajo) y contador de intentos.
- [ ] `05_sistema_notas/` — Registro de notas de alumnos, cálculo de promedio, nota más alta/baja y estado (Aprobado/Reprobado).
- [ ] `06_sistema_inventario/` — CRUD básico en consola (agregar, ver, actualizar stock, eliminar productos) usando diccionarios o listas.
- [ ] `07_agenda_contactos/` — Agenda telefónica con búsqueda por nombre, edición y eliminación de contactos.
- [ ] `08_cajero_automatico/` — Simulación de ATM con PIN de seguridad, consulta de saldo, depósitos, retiros y validación de fondos.
- [ ] `09_registro_usuarios/` — Sistema de login y registro en consola con validación de contraseña segura y persistencia simple en archivo o memoria.
- [ ] `10_gestion_tareas/` — Lista To-Do en consola con estados (pendiente/completada) y opciones para marcar y listar.

---

## 🏆 Proyecto de Etapa: Sistema de Gestión Personal

Desarrollar una aplicación completa de consola en `proyecto_gestion_personal/` que integre todos los conceptos aprendidos:

**Requisitos:**
- [ ] Crear, listar, modificar y eliminar tareas.
- [ ] Marcar tareas como completadas / pendientes.
- [ ] Filtrar y buscar tareas por título o categoría.
- [ ] Mostrar estadísticas (total de tareas, porcentaje completado, tareas pendientes).
- [ ] Manejo exhaustivo de errores (entradas inválidas no deben tumbar el programa).
- [ ] Código modular dividido en funciones y/o archivos separados.
