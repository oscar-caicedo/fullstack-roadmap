# 🧠 Etapa 2 — Algoritmos y Lógica de Programación

### 🎯 Objetivo
Desarrollar el pensamiento algorítmico, dejar de memorizar código y aprender a resolver problemas de lógica de forma estructurada e intuitiva.

---

## 📚 Conceptos Clave
- [ ] Pseudocódigo y diagramas de flujo.
- [ ] Análisis de complejidad básica (Notación Big-O intuitiva: tiempo vs. memoria).
- [ ] Algoritmos de búsqueda: lineal y binaria.
- [ ] Algoritmos de ordenamiento: Bubble sort, Insertion sort, Merge sort (conceptos básicos).
- [ ] Recursividad básica vs. iteración.
- [ ] Manipulación avanzada de listas, strings y diccionarios (conteo de frecuencias, agrupaciones, filtros).

---

## 🏆 Proyecto de Etapa: App de Análisis de Datos y Estadísticas
Crear una aplicación que reciba un conjunto de datos numéricos y calcule:
- [ ] Mínimo y Máximo (sin usar `min()` o `max()` en la primera versión para ejercitar lógica).
- [ ] Promedio (Media aritmética).
- [ ] Mediana y Moda (cálculo de frecuencias).
- [ ] Ordenamiento de datos.
- [ ] Búsqueda de elementos con reporte de posición o ausencia.
