# 📦 Etapa 3 — Programación Orientada a Objetos (POO)

### 🎯 Objetivo
Modelar problemas del mundo real mediante entidades y objetos, aplicando los 4 pilares fundamentales de la POO.

---

## 📚 Conceptos Clave
- [ ] Clases y Objetos (Instanciación).
- [ ] Atributos de instancia y atributos de clase.
- [ ] Métodos y el parámetro `self`.
- [ ] Constructores (`__init__`) y representación (`__str__`, `__repr__`).
- [ ] Encapsulación (atributos privados `_` y `__`, getters, setters, `@property`).
- [ ] Herencia y reutilización de código (`super()`).
- [ ] Polimorfismo y sobreescritura de métodos.

---

## 🏆 Proyecto de Etapa: Sistema E-commerce / Inventario Orientado a Objetos
Evolucionar el sistema de inventario modelando clases:
- [ ] `Producto` (id, nombre, precio, stock, descripción).
- [ ] `ProductoDigital` / `ProductoFisico` (herencia de Producto).
- [ ] `Usuario` / `Cliente` (id, nombre, email, historial).
- [ ] `Carrito` (agregar producto, quitar producto, calcular subtotal/impuestos/descuentos).
- [ ] `Venta` / `Orden` (generar ticket, rebajar stock, registrar transacción).
- [ ] `Inventario` (gestionar catálogo y búsquedas).
