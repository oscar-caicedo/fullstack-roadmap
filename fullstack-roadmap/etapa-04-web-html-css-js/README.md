# 🌐 Etapa 4 — Desarrollo Web desde Cero (HTML, CSS y JavaScript)

### 🎯 Objetivo
Aprender la tríada fundamental de la web: estructuración semántica (HTML), estilizado responsivo (CSS) e interactividad y manipulación del DOM (JavaScript).

---

## 📚 Conceptos Clave

### HTML5
- [ ] Estructura básica de un documento HTML5.
- [ ] Etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- [ ] Formularios, inputs, botones, labels y validación nativa.
- [ ] Tablas, listas, enlaces e imágenes accesibles (`alt`).

### CSS3
- [ ] Selectores, especificidad y cascada.
- [ ] Modelo de caja (*Box Model*): content, padding, border, margin.
- [ ] Flexbox (layouts unidimensionales) y CSS Grid (layouts bidimensionales).
- [ ] Posicionamiento (`static`, `relative`, `absolute`, `fixed`, `sticky`).
- [ ] Diseño Responsivo con Media Queries (`@media`).

### JavaScript (Fundamentos Web)
- [ ] Manipulación del DOM (`document.querySelector`, `createElement`, `appendChild`).
- [ ] Eventos y listeners (`addEventListener`, `event.preventDefault()`).
- [ ] Persistencia con `localStorage` y `sessionStorage`.
- [ ] Asincronía básica: Promesas, `async / await` y `fetch` para consumir APIs públicas.
