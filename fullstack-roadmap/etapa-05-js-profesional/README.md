# ⚡ Etapa 5 — JavaScript Profesional y Moderno (ES6+)

### 🎯 Objetivo
Dominar JavaScript a profundidad antes de dar el salto a frameworks frontend, aprendiendo patrones modernos, asincronía y modularización.

---

## 📚 Conceptos Clave
- [ ] ES6+: `let`/`const`, arrow functions, template literals, default parameters.
- [ ] Destructuring (objetos y arrays) y operadores Rest / Spread (`...`).
- [ ] Módulos ES (`import` / `export`).
- [ ] Scope, Hoisting, Closures y Contexto (`this`).
- [ ] Higher-Order Functions y métodos de array (`map`, `filter`, `reduce`, `find`, `some`, `every`).
- [ ] Promesas en profundidad, `Promise.all()`, manejo de errores con `try / catch` en async/await.
- [ ] Arquitectura modular: separación de responsabilidades (UI, Estado, Servicios API).

---

## 🏆 Proyecto de Etapa: Refactorización Modular de la Tienda
Reescribir la tienda web separando el código en módulos ES:
- [ ] `services/api.js` (comunicación asíncrona).
- [ ] `services/storage.js` (persistencia local).
- [ ] `components/cart.js`, `components/productCard.js` (lógica de renderizado).
- [ ] `state/store.js` (gestión centralizada del estado del carrito).
