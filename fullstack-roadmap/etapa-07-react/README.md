# ⚛️ Etapa 7 — Frontend Moderno con React

### 🎯 Objetivo
Aprender la librería líder de frontend para construir interfaces de usuario declarativas, reactivas y basadas en componentes reutilizables.

---

## 📚 Conceptos Clave
- [ ] Creación de proyectos con Vite / React (`npm create vite@latest`).
- [ ] Componentes funcionales y sintaxis JSX / TSX.
- [ ] Props: paso de datos y callbacks entre componentes.
- [ ] Estado con `useState`: inmutabilidad y re-renders.
- [ ] Efectos con `useEffect`: ciclo de vida, llamadas a APIs y limpieza.
- [ ] Formularios controlados y manejo de eventos.
- [ ] Enrutamiento en SPA con React Router (`react-router-dom`).
- [ ] Estado global básico con Context API (`createContext`, `useContext`).
- [ ] Custom Hooks para reutilización de lógica (`useCart`, `useFetch`).

---

## 🏆 Proyecto de Etapa: SPA Tienda Web en React + TypeScript
- [ ] Vistas: Catálogo, Detalle de Producto, Carrito, Checkout.
- [ ] Carrito sincronizado mediante Context API o Zustand.
- [ ] Manejo de estados de carga (Loading, Error, Success).
