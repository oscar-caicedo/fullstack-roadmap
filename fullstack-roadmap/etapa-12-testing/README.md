# 🧪 Etapa 12 — Testing y Calidad de Software

### 🎯 Objetivo
Garantizar la estabilidad y confiabilidad de la aplicación mediante pruebas automatizadas en Frontend y Backend.

---

## 📚 Conceptos Clave
- [ ] Pirámide de testing: Unit tests, Integration tests, E2E tests.
- [ ] Testing en Backend con Jest / Vitest y Supertest (probar endpoints HTTP y lógica de negocio).
- [ ] Testing en Frontend con React Testing Library y Vitest (renderizado de componentes, eventos de usuario).
- [ ] Mocks, Spies y Stubs para servicios externos y bases de datos en tests unitarios.
- [ ] Cobertura de código y testing en flujos críticos (login, compra, cálculo de totales).
