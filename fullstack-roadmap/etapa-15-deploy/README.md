# 🚀 Etapa 15 — Despliegue a Producción (Deploy)

### 🎯 Objetivo
Llevar la aplicación a la web pública con dominio propio, certificados SSL (HTTPS), logs de producción y base de datos gestionada.

---

## 📚 Conceptos Clave
- [ ] Opciones de hosting modernas: VPS (DigitalOcean/Hetzner/AWS EC2) vs PaaS (Render, Railway, Fly.io, Vercel).
- [ ] Configuración de Reverse Proxy con Nginx o Caddy.
- [ ] Certificados SSL gratuitos y automáticos con Let's Encrypt / Certbot.
- [ ] Variables de entorno de producción y seguridad de secrets.
- [ ] Monitorización básica y lectura de logs en producción.
