# 🏆 Proyecto Final Full Stack

### 🎯 Objetivo
Construir una aplicación web completa de nivel profesional que integre de principio a fin todos los conocimientos adquiridos a lo largo de este roadmap.

---

## 🏛️ Arquitectura del Proyecto

```text
React + TypeScript (Frontend)
       ↓  (HTTP / REST / JSON)
Node.js + Express + TypeScript (Backend API)
       ↓  (SQL / ORM)
PostgreSQL (Base de Datos)
       ↓
Docker & Docker Compose (Contenedores)
       ↓
Linux / Servidor Cloud (Infraestructura)
       ↓
Internet (Dominio + HTTPS)
```

---

## 📋 Requisitos Obligatorios
- [ ] **Frontend**: SPA reactiva en React + TypeScript con rutas, componentes modulares, estado centralizado y UI pulida y responsiva.
- [ ] **Backend**: REST API en Node.js + Express con validaciones, manejo global de errores y arquitectura en capas.
- [ ] **Persistencia**: PostgreSQL con relaciones bien diseñadas e integridad referencial.
- [ ] **Seguridad**: Autenticación JWT, contraseñas hasheadas y roles diferenciados (Cliente y Administrador).
- [ ] **Testing**: Pruebas unitarias e integración de flujos clave.
- [ ] **DevOps**: Dockerfile y docker-compose funcionales para levantar todo el stack.
- [ ] **Producción**: Despliegue en servidor real accesible vía URL pública con HTTPS.
- [ ] **Documentación**: README completo con instrucciones de instalación, variables de entorno y diagramas de arquitectura.
